# WordRunes Assets

Public game asset catalog served as a CDN for the WordRunes app.

- `assets/avatars/` — avatar artwork (PNG)
- `catalog/avatars.json` — avatar catalog (id, cost, category, label key, image URL)

The catalog JSON is fetched by the app and merged with the built-in avatar list,
so new avatars / price changes appear without an app update.

Base URL: **https://sitebytom.github.io/wordrunes-assets/**
